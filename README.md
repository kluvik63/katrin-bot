# 🤖 KATRIN PRO VITAMIN — Бизнес-консультант

Telegram бот с ИИ-консультантом для управляющей магазина.

---

## 📁 Файлы проекта

- `bot.py` — основной код бота
- `requirements.txt` — список библиотек
- `README.md` — эта инструкция

---

## 🚀 Пошаговый запуск на Railway

### Шаг 1 — Загрузи файлы на GitHub

1. Зайди на **github.com** → войди в аккаунт
2. Нажми зелёную кнопку **"New"** (создать репозиторий)
3. Название: `katrin-bot`
4. Нажми **"Create repository"**
5. На открывшейся странице нажми **"uploading an existing file"**
6. Перетащи все 3 файла (`bot.py`, `requirements.txt`, `README.md`)
7. Нажми **"Commit changes"**

---

### Шаг 2 — Узнай свой Telegram ID

1. Открой Telegram
2. Найди бота **@userinfobot**
3. Напиши ему `/start`
4. Он ответит твой ID — запомни это число (например: `123456789`)
5. Попроси управляющую сделать то же самое

---

### Шаг 3 — Вставь токены в bot.py

Открой файл `bot.py` в GitHub и найди строки:

```python
ALLOWED_USERS = []  # Пример: [123456789, 987654321]
```

Замени на ID управляющей:
```python
ALLOWED_USERS = [ID_управляющей]  # например: [987654321]
```

---

### Шаг 4 — Разверни на Railway

1. Зайди на **railway.app**
2. Нажми **"New Project"**
3. Выбери **"Deploy from GitHub repo"**
4. Подключи свой GitHub аккаунт → выбери `katrin-bot`
5. Railway начнёт загружать проект

---

### Шаг 5 — Добавь переменные окружения (секреты)

В Railway → твой проект → вкладка **"Variables"** → добавь:

| Ключ | Значение |
|------|----------|
| `BOT_TOKEN` | токен от BotFather (7412345678:AAF...) |
| `CLAUDE_API_KEY` | ключ Claude (sk-ant-...) |

---

### Шаг 6 — Настрой запуск

В Railway → **Settings** → **Start Command** → введи:
```
python bot.py
```

Нажми **"Deploy"** — через 1-2 минуты бот запустится!

## 💬 Как пользоваться

**Управляющая просто пишет вопросы:**
- "Как мотивировать продавца который не выполняет план?"
- "Придумай акцию на следующую неделю"
- "Объясни почему выручка упала на 15%"
- "Напиши скрипт для продажи омеги-3"
- "Как правильно провести собеседование?"

**Команды:**
- `/start` — начало работы
- `/clear` — сбросить историю диалога
- `/myid` — узнать свой ID

---

## ⚠️ Важно

- Бот помнит диалог пока работает (до перезапуска)
- После `/clear` история стирается — начинается новый разговор
- Стоимость: ~$0.01-0.05 за один диалог (очень дёшево)
